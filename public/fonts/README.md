# Fonts

Hier die Font-Dateien für **PP Watch** ablegen, mit genau diesen Dateinamen:

- `PPWatch-Bold.woff2` – Titel
- `PPWatch-Extralight.woff2` – Nummern und Namen auf den Standort-Karten

Die Dateien sind in `src/index.css` per `@font-face` eingebunden. Solange sie fehlen, greift die Ersatzschrift (Arial Black bzw. Arial).
